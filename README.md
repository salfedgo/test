# Игра в бутылочку

Простая консольная реализация игры "бутылочка" на Python. Можно указать
имена игроков через аргументы командной строки или ввести их вручную.

## Запуск

```bash
python bottle_game.py Alice Bob Carol Dave
```

По умолчанию игра длится бесконечно. Чтобы ограничить число вращений,
используйте флаг `--rounds`:

```bash
python bottle_game.py Alice Bob --rounds 5
```
